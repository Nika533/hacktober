## Notes

### Using `@hoot/ui` (d1: Buddy, capture, note)

```tsx
import '@hoot/ui/styles.css'
import { HootUIProvider, applyTheme, applyAccent } from '@hoot/ui'

applyTheme(system.darkMode ? 'dark' : 'light')
applyAccent(system.accentColor) // '#RRGGBB' or Electron's 'RRGGBBAA'; null resets
root.render(<HootUIProvider><App /></HootUIProvider>)
```

- `Owl` takes `gaze={{ x, y }}` (from `buddy.onCursor`) and bumps
  `talkSignal` on each `chat.onDelta`. Under reduced motion each mood keeps
  a still pose, so moods stay readable.
- `Button` and `IconButton` pass every other prop through, so `data-hit`
  still works.
- Text is selectable by default. Add `.hoot-chrome` to chrome that
  shouldn't be.
- `useToast().show({ message, action: { label: 'Undo', onAction } })` and
  `await useConfirm()({ title, confirmLabel, tone: 'danger' })`.

### Buddy card with the chat components (D1-15)

```tsx
<Transcript
  messages={session.messages.map((m) => ({
    id: m.id, role: m.role, text: m.text, status: m.status, error: m.error,
    attachments: m.attachmentIds.flatMap((id) => {
      const a = session.attachments[id]
      return a ? [{ id, thumbUrl: a.thumbDataUrl }] : []
    })
  }))}
  onRegenerate={() => hoot.chat.regenerate()}
  onPin={(id) => hoot.pins.create(id)}
  onCopy={(t) => hoot.clipboard.writeText(t)}
  onAddKey={() => hoot.windows.openStudio('settings')}
/>
{hint && <ClipboardChip kind={hint.kind} chars={hint.chars} armed={!!hint.selected}
  onToggle={() => hoot.clipboard.arm()} onDismiss={() => hoot.clipboard.dismiss()} />}
<AttachmentsRow attachments={pending} onRemove={(id) => hoot.attachments.remove(id)} />
{pending.length > 0 && <QuickChips actions={quick} onPick={(id) => hoot.chat.send({ quickAction: id })} />}
<Composer streaming={!!stream} onSend={(text) => hoot.chat.send({ text })}
  onStop={() => hoot.chat.stop()}
  onEmptySend={pending.length ? () => hoot.chat.send({ quickAction: 'explain' }) : undefined} />
```

- `quick` = `(Object.keys(QUICK_ACTIONS) as QuickActionId[]).map((id) => ({ id,
  label: QUICK_ACTIONS[id].label }))`, from core's prompt catalogue.
- `Transcript` fills a flex column parent (`flex: 1; min-height: 0`).
- Remount `Composer` with a new `key` to reseed it (Explain more).

### Design decisions

- **Windows first, Apple motion.** Windows 11 control conventions (dialog
  footer, arrow cursor, Segoe UI Variable optical families) with the
  apple-design skill's springs, feedback on pointer-down, and symmetric
  enter and exit.
- **The owl is the one bold element.** The accent is the user's Windows
  accent, and `onAccentFor()` keeps text on it at AA contrast.
- **Native first.** Segmented, Switch, Slider and Dialog are built on radios,
  a checkbox, a range input and `<dialog>`.
- **Destructive confirms focus Cancel.** Use Undo toasts for everything
  reversible.
