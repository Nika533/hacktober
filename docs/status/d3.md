## Notes

### Using `@hoot/ui` (d1: Buddy, capture, note)

```tsx
import '@hoot/ui/styles.css'
import { HootUIProvider, applyTheme, applyAccent } from '@hoot/ui'

applyTheme(state.system.darkMode ? 'dark' : 'light') // or 'system'
applyAccent(state.system.accentColor) // '#RRGGBB' or Electron's 'RRGGBBAA'; null resets
// If Windows transparency effects are off and the media query doesn't fire:
document.documentElement.dataset.transparency = 'reduce'

root.render(<HootUIProvider><App /></HootUIProvider>)
```

- `Owl` no longer reads `window.hoot`. Pass `gaze={{ x, y }}` (cursor offset
  from the owl centre) and bump `talkSignal` on each `chat:delta`. Without
  `talkSignal` a talking owl flaps its beak on a steady beat. Under reduced
  motion each mood keeps a still pose (thinking tilts, listening perks its
  tufts, celebrate shows a still ring, error squints), so moods stay readable.
- `IconButton` and `Button` pass every other prop through to the `<button>`,
  so `data-hit` for click-through still works.
- Text is selectable by default. Add `.hoot-chrome` to chrome that shouldn't
  be. Legacy set `user-select: none` globally.
- Overlays: `useToast().show({ message, action: { label: 'Undo', onAction } })`
  and `await useConfirm()({ title, confirmLabel, tone: 'danger' })`.

### Buddy card with the chat components (d1, D1-15)

```tsx
<Transcript
  messages={session.messages.map(toView)} // see Requests 5
  onRegenerate={() => hoot.chat.regenerate()}
  onPin={(id) => hoot.pins.create(id)}
  onCopy={(t) => hoot.clipboard.writeText(t)}
  onOpenLink={(href) => hoot.openExternal(href)}
  onAddKey={() => hoot.windows.openSettings()}
/>
{hint && <ClipboardChip kind={hint.kind} chars={hint.chars} armed={!!hint.selected}
  onToggle={hoot.clipboard.arm} onDismiss={hoot.clipboard.dismiss} />}
<AttachmentsRow attachments={pending} onRemove={hoot.capture.removeAttachment} />
{pending.length > 0 && <QuickChips actions={QUICK} onPick={(id) => hoot.chat.send({ quickAction: id })} />}
<Composer streaming={streaming} onSend={(text) => hoot.chat.send({ text })}
  onStop={hoot.chat.stop} onEmptySend={pending.length ? () => hoot.chat.send({ quickAction: 'explain' }) : undefined}
  actions={<IconButton label="Circle anything" size="sm"><PencilLine /></IconButton>} />
```

- The `hoot.*` names above are placeholders until C-02 freezes `HootApi`.
- `Transcript` fills its flex parent (`flex: 1; min-height: 0`). Give the
  card a fixed height and a column layout.
- Stream deltas by updating `text` on the message. Markdown is memoised per
  message, so only the streaming message re-renders.
- Remount `Composer` with a new `key` to reseed it (for "Explain more"
  pre-fill).

### Design decisions

- **Windows first, Apple motion.** Controls follow Windows 11: the dialog
  footer puts the primary action first with equal-width buttons on a recessed
  band, the default cursor stays an arrow, and the type is Segoe UI Variable
  (Display, Text and Small optical families). Motion follows the apple-design
  skill: critically damped springs, feedback on pointer-down, and enter and
  exit along the same path.
- **The owl is the one bold element.** Everything else is quiet and neutral,
  and the accent is the user's Windows accent. `onAccentFor()` picks a text
  colour that passes AA on any accent.
- **Native first.** Segmented uses radios, Switch uses a checkbox with
  `role="switch"`, Slider uses a range input, and Dialog uses `<dialog>`, so
  keyboard support, screen-reader semantics and focus containment come from
  the platform.
- **Focus on destructive confirms goes to Cancel.** A confirm only appears
  for irreversible actions; everything else should use Undo toasts.
